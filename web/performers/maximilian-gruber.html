Biography

Maximilian Gruber is an inference engineer at TensorServe who works on the low-level mechanics of model serving. He is best known for practical write-ups on GPU memory and request scheduling.

Talk

Memory Management and KV-Cache Compression in LLM Serving

KV-cache memory is often the true limit on LLM serving. Maximilian Gruber looks inside the serving stack and compares compression and eviction techniques that increase throughput on the same hardware.
