Biography

Diana Vance is backend lead at SwiftServe Cloud, running high-traffic API platforms in Python. She specialises in reducing inference bills through caching and smarter request routing.

Session at Futurika Fest

Day 3 (23 May) · 16:30–17:15

Live Coding

Semantic Caching for High-Throughput LLM APIs

Diana Vance adds semantic caching to a high-traffic LLM API live on stage. Watch the costs and response times change, then see how to avoid serving stale or incorrect answers.
