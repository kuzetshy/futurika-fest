Questions about the programme

How long is a session?

Every session lasts 45 minutes. Sessions start every hour, so there are 15 minutes to change rooms.

Can I attend two sessions at the same time?

No. Both stages run at the same time. When you save a session, the programme shows which other saved session it overlaps with.

What do Beginner, Intermediate and Advanced mean?

The level shows how much background knowledge a session expects. Each performer page also lists the prerequisites.

Do I need to bring a laptop?

Only for some workshops and live coding sessions. Check the prerequisites on the performer page.
